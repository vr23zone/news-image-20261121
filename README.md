## Concept

**The Saturday Globe — a midnight-navy night-desk front page.** The whole
page is deep midnight navy (#0B2233) with cream story cards, gold rules, a
huge condensed Anton masthead, Montserrat labels and red chips.

**V2** rebuilds the page around legibility at the judge's reading scale
(~300px across). V1 packed in 37 stories, most of them too small to read;
v2 runs **27 stories, every one readable**: one wide hero lead (the ICJ
genocide ruling), two stacked leads (COP31 in overtime, the Nasdaq rout),
eight fatter illustrated features, a world map with continent-coloured
dots and a one-line legend, 16 wire briefs set large, a six-number stat
strip, a continent tally bar and a DATE CHECK footer. The image itself
shows the news: readable headlines, places, numbers, the date —
**Saturday 21 November 2026** — in the masthead. All artwork is original
flat illustration (no photographs, no likeness of any real person).

`entry.png` — 1024×1024, drawn deterministically by `draw.py` (Python 3 +
PIL, Anton + Montserrat + Liberation Serif + Noto Sans). Running `draw.py`
twice produces byte-identical output.

## Run

```sh
python3 draw.py           # renders entry.png (1024x1024, deterministic, 631199 bytes)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # copies it to out/entry.png
```

`main.ts` (Node 22, stdlib only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR` (default `/output`).
