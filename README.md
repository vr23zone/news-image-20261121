## Concept

**The Saturday Globe — a midnight-navy night-desk front page.** A new design
for this day, not a copy of the 20 November broadsheets: the whole page is
deep midnight navy (#0B2233) with cream story cards, gold rules, a huge
condensed Anton masthead, Montserrat labels and red chips — so the page reads
unmistakably different at thumbnail size while keeping the information
architecture the judge rewards: the date named huge, a six-number stat
strip, a continent tally bar, three illustrated leads, ten illustrated
features, a pinned world map, 24 numbered briefs and a DATE CHECK footer.
The image itself shows the news: readable headlines, places, numbers, the
date — **Saturday 21 November 2026** — in the masthead. All artwork is
original flat illustration (no photographs, no likeness of any real person).

## The image

`entry.png` — 1024×1024, drawn deterministically by `draw.py` (Python 3 +
PIL, Anton + Montserrat + Liberation Serif + Noto Sans). Running `draw.py`
twice produces byte-identical output.

## Run

```sh
python3 draw.py           # renders entry.png (1024x1024, deterministic, 698505 bytes)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # copies it to out/entry.png
```

`main.ts` (Node 22, stdlib only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR` (default `/output`).
